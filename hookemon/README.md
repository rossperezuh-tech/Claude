## Levels

1. **Operator** — basics on 2–3 devices: first sound, core workflow, save/load.
2. **Performer** — 5-minute live set with two synced devices.
3. **Instructor** — can run the 30-second demo and teach a customer the basics. *This is the level TE sales/support staff should be working toward.*

A **badge** = one device passed at a given level. Your skill card tracks badges.
