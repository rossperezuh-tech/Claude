# Run of Show — Saturday

Assumes **3 hours** and **~12–20 people**. Scale stations to headcount (aim for 3–5 people per station).

| Time | Block | Notes |
|---|---|---|
| 0:00–0:10 | **Open** | Who you are, why this matters: customers buy what they see someone use with confidence. Explain levels + badges in 2 minutes. |
| 0:10–0:25 | **Live demo** | You play something short across 2–3 devices synced. Then break down what they just heard in plain language. This sets the bar. |
| 0:25–0:35 | **Shared vocabulary** | Quick run through the terms from survey Q6 that most people *didn't* check. Keep it to 5–6 terms max. |
| 0:35–1:35 | **Stations, round 1** | 3 rotations × 20 min. Groups assigned from survey. See `03-stations.md`. |
| 1:35–1:45 | Break | |
| 1:45–2:15 | **Sell it** | Demo scripts + objection handling (`05-sell-it.md`). Pair up: one is the customer, one demos. Swap. |
| 2:15–2:40 | **Badge attempts** | Everyone attempts at least one badge challenge (`04-badges-and-homework.md`). You sign off. |
| 2:40–2:50 | **Hard questions** | Answer the survey Q10 list live. |
| 2:50–3:00 | **Close** | Hand out homework (one MIDI task each). Post-survey (`07-post-survey.md`). Mention next steps. |

## Setup checklist

- [ ] Each station: device(s), charged, headphones + headphone splitter, a small speaker
- [ ] Factory-reset or known-state demo units (or a saved project you can reload)
- [ ] Gearbase MIDI files loaded where needed + a laptop with MIDI out for sync demos
- [ ] Printed skill cards (one per person, pre-filled from survey)
- [ ] Printed station sheets
- [ ] QR code to the post-survey
- [ ] Cables: USB-C, 3.5mm, sync cables, MIDI adapters

## If you're short on time (2 hours)

Cut shared vocabulary to 5 min, stations to 2 rotations, Sell it to 20 min, badges to 15 min, drop the hard-questions block (answer by email after).
