# The Prompt Sherpa — thepromptsherpa.com

Marketing site + build intake app for The Prompt Sherpa
(Claude consulting & Claude Code builds for early-stage entrepreneurs —
MVPs, landing pages, prototypes).

- `/` — marketing site
- `/intake` — build intake app (answers autosave to `localStorage`,
  same storage key as the original single-file version so saved
  answers carry over)

## Run

```bash
npm install
npm run dev   # http://localhost:3002
```

## Brand

Lime `#4A7A0C` on green-tinted mist `#F5F7F2` · Space Grotesk
(headings) · Inter (body). Tokens live in `tailwind.config.ts`.
