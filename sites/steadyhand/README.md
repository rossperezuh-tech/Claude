# Steadyhand — steadyhand.ai

Marketing site + client intake app for Steadyhand AI Consulting
(Claude workflow optimization and private/local LLM setup for
established small businesses).

- `/` — marketing site
- `/intake` — project intake app (answers autosave to `localStorage`,
  same storage key as the original single-file version so saved
  answers carry over)

## Run

```bash
npm install
npm run dev   # http://localhost:3001
```

## Brand

Teal `#1F6F66` on warm cream `#F6F5F1` · Newsreader (headings) ·
Inter (body). Tokens live in `tailwind.config.ts`.
